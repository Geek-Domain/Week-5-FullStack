# Week 5 — Full-Stack Learning Project

A historical full-stack development exercise with separate frontend and backend directories.

## Repository structure

- `Frontend/`: frontend application code.
- `Backend/`: backend application code, routes, models, middleware and database-related files.

## Current status

Preserved for future completion. Live deployment and functionality have not been verified.

## Security and setup

An old environment file was removed from the current branch. Previously committed secrets may remain in Git history and must not be reused. Before running or deploying this project, create fresh database credentials and a new JWT signing secret, then supply them through locally managed environment settings.

Install dependencies from each application's package manifests. Do not commit `.env` files or `node_modules` folders.
